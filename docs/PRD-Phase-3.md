# Phase 3 - Expansion

## Goal

Expand the product from a simple shared tracker into a more flexible household operating layer without losing the lightweight feel.

## Deliverables

- Add richer scheduling logic for more edge cases
- Explore templates for common household chore sets
- Support larger household structures if still desired
- Add optional deeper statistics or trends around chore completion
- Explore integrations or automation hooks if they add clear value
- Improve personalization of reminders, categories, and household routines

## Why This Phase Exists

Once the core loop is working well, this phase can widen the product's usefulness. The priority is not scale for its own sake, but selectively adding features that keep the product simple while covering more real household situations.

## Risks

- Expansion can easily bloat the product beyond the original personal-project goal.
- More sophisticated scheduling may require more complex UX than users want.
- Integrations may add maintenance burden that is not worth it for a low-cost project.

## Open Questions

- Should this remain a personal project or become something shareable with a broader audience?
- Which advanced scheduling or automation features are actually worth building?
- At what point does broader household support create too much complexity?
